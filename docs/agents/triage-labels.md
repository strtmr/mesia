# Triage-Labels

Die Skills sprechen von fünf festen Triage-Rollen. Diese Datei ordnet ihnen die Label-Namen im Issue-Tracker zu.

| Label in mattpocock/skills | Label in unserem Tracker | Bedeutung                                        |
| -------------------------- | ------------------------ | ------------------------------------------------ |
| `needs-triage`             | `needs-triage`           | Muss noch bewertet werden                        |
| `needs-info`               | `needs-info`             | Wartet auf weitere Informationen                 |
| `ready-for-agent`          | `ready-for-agent`        | Vollständig beschrieben, ein Agent kann loslegen |
| `ready-for-human`          | `ready-for-human`        | Muss ein Mensch umsetzen                         |
| `wontfix`                  | `wontfix`                | Wird nicht umgesetzt                             |

Nennt ein Skill eine Rolle (z. B. „das AFK-Label setzen“), gilt der Label-Name aus der rechten Spalte.

Die rechte Spalte lässt sich anpassen, falls andere Namen verwendet werden.
